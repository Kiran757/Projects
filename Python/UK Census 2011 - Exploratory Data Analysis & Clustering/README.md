# Census Analysis - UK Census 2011

**Python Data Analysis & Unsupervised Machine Learning**

End-to-end exploratory data analysis and clustering on the UK Census 2011 dataset (England & Wales).

## 📋 Project Highlights
- Loaded and cleaned 569,740 records
- Comprehensive EDA with univariate & bivariate analysis
- Data labeling and feature engineering
- Applied **Gaussian Mixture Model (GMM)** clustering
- Used **PCA** for dimensionality reduction and visualization

## 🛠️ Technologies
- Python, Jupyter Notebook
- pandas, numpy, seaborn, matplotlib
- scikit-learn (GMM + PCA)
