# Amazon Reviews Sentiment Analysis

**Natural Language Processing (NLP) Project**

Binary sentiment classification and topic modeling on Amazon cell phone reviews.

## 📋 Project Highlights
- Processed 1,000 balanced customer reviews
- Text preprocessing (lowercasing, stopword removal, tokenization)
- Feature extraction using CountVectorizer & TF-IDF
- Built multiple classification models
- Performed **LDA** and **LSA** topic modeling

## 🛠️ Technologies
- Python, Jupyter Notebook
- NLTK, scikit-learn, Gensim, pyLDAvis

## 📁 Files
- `IDATA2.ipynb`
- Full NLP pipeline and model evaluation
