# Stroke Prediction - Healthcare Dataset

**Python Data Analysis & Preprocessing**

Exploratory data analysis and preparation for stroke prediction using a real healthcare dataset.

## 📋 Project Highlights
- Analyzed 5,110 patient records
- Handled severe class imbalance (~5% stroke cases)
- Data cleaning and missing value treatment
- Feature encoding and scaling (MinMaxScaler + LabelEncoder)
- Comprehensive EDA with visualizations

## 🛠️ Technologies
- Python, Jupyter Notebook
- pandas, numpy, seaborn, matplotlib, scikit-learn

## 📁 Files
- `Programming.ipynb`
- Full preprocessing pipeline ready for modeling
