# MongoDB - FM Clothing Store (NoSQL)

**Coursework 2 - Data Management**

Document-oriented database implementation using MongoDB for the same FM Clothing Store case study.

## 📋 Project Highlights
- 7 Collections with proper embedding & referencing
- Advanced **Aggregation Pipelines** (5 business queries)
- Used `$lookup`, `$unwind`, `$group`, `$addToSet`, etc.

## 🔍 Key Queries Implemented
1. All orders with customer, product & category details
2. Total revenue per store + product/category breakdown
3. Customers who bought from multiple categories
4. Products sold by each store with category details
5. Total orders, revenue & unique customers per store

## 🛠️ Technologies
- MongoDB
- MongoDB Aggregation Framework
- MongoDB Shell
